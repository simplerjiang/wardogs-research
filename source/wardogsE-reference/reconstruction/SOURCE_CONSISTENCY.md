# 第十二轮：来源一致性读回与缓存失效

2026-10-22。本轮只运行自有字节数组和透明测试窗口，不接触现场助手、游戏、驱动、
路线 A 或系统配置。保留旧项目。参考行为来自已保存伪代码、汇编及异常表的静态检查。

## 读回比较的实际范围

`reference_consistency` 对应 fgnew 的7468外层：最初读取pawn→mesh和共同描述基址，
每次尝试先保存摘要，调用姿态收集，再读回摘要；摘要一致时最后重新读取pawn→mesh。
最多调用收集两次。重试仍使用最初mesh和描述基址，内层收集则重新读取mesh。

32字节摘要并非两个16字节描述原样拷贝：

| 偏移 | 内容 |
|---|---|
| 0、8 | 两个骨数组地址，各64位 |
| 16、20 | 两个骨数组数量，各32位 |
| 24 | 首选标记，32位，默认-1 |
| 28 | 初始化为零的填充 |

capacity、骨变换、component内容、名字记录、asset和对象代际均不在比较中。
`stable` 仅表示这些摘要及最终mesh比较通过，不表示原子快照或完整对象图一致。

## 失败与缓存动作

| 事件 | 参考分支和本地模型动作 |
|---|---|
| 最初mesh为空或骨描述基址不可用 | 空输出；保留已有姿态缓存 |
| 采集前主数组地址/数量读取失败 | 立即返回，不在此分支清缓存，不再调用本次收集 |
| 前后首选标记读取失败 | 返回状态被忽略，缓冲默认-1；部分写入也保留 |
| 采集前副数组通过ab80，但后续地址/数量读取失败 | 返回状态被忽略，保留初始零值或已写入的前缀；不能改为统一提前拒绝 |
| 采集前副数组为空，采集后变为有效 | 拒绝本次结果、清当前pawn的姿态缓存，尝试剩余一次 |
| 采集后主数组或需要读取的副数组读取失败 | 清输出mask和当前pawn的姿态缓存，最多两次收集 |
| 摘要变化或最终mesh与最初值不同 | 同上；重试不刷新最初mesh基准 |
| 内层ab80验证短读 | 内层早退可保留姿态缓存；外层仍独立判断读回是否一致 |
| ab80通过后逐关节读取短读导致姿态选择失败 | 内层清姿态缓存；摘要可能仍一致 |
| 上述任意外层拒绝 | 不清动态映射缓存，不回滚内层已产生的映射插入/命中 |
| selected context变化 | 仍按第十一轮规则清两类缓存，保留学习签名 |

外层实现保留收集结果中的点位和诊断字段，只清mask。窗口发布把摘要通过和候选选择
分别判断，拒绝帧使用零mask产生空绘制，不重复呈现上次骨骼。

7344本身是范围检查后内存复制，不提供已复制字节数。静态异常表及逐字节复制代码支持
“某些复制异常可能已经写入前缀，然后返回失败”，不能把每次false都说成真实短读。
测试用Reader写入部分字节再返回false来表达这一接口边界；没有触发真实访问异常。
7318读取失败时返回零，而7468中忽略返回值的目标缓冲不被额外清零。
已确认的复制异常处理分支调用90f4清范围保护缓存的选中槽；它与姿态/映射缓存分开，
也不同于范围检查提前失败。本轮只静态确认该分支，没有执行Windows异常路径。

## 地址复用和检测限制

- 相同asset/名字数组地址/数量键命中时不读名字内容；即使原对象已被同地址新对象替换，
  本模型也无法识别代际。上下文清理或换键后才会重新解析。
- A→B→A在采样间发生并恢复，端点比较可以通过。本轮受控数据让内层实际读B数组，
  返回前恢复A地址，因此接受的绘制与原A绘制不同。没有把这一结果称为“解决ABA”。
- 骨数组内容在逐关节读取中变化，但摘要保持相同，也可以通过。受控场景在读取raw20时
  修改尚未读取的raw21，输出随之变化；这不能证明整帧来自同一时刻。
- capacity未直接比较；其变化可能经ab80间接影响路径，但不能依赖摘要必定发现。
- 姿态缓存只保存选择提示，不保存整套姿态。缓存命中仍使用当前收集到的变换。

没有新增TTL、代际字段、哈希、自动全量清缓存或额外重试。

## 受控集成边界

`ControlledSession` 在已有动态映射和两类缓存外围调用`read_consistent_pose`。
内层仍先物化两个骨数组，再调用纯姿态模型；这不是76e4逐pass实时读取时序的完整复刻。
静态异常处理涉及的范围保护缓存仍由`RangeCheck`抽象，本轮没有实现Windows范围探测、
异常处理或由真实异常触发的保护缓存清理。

故障脚本只改自有数组或Reader返回值。额外地址0xa0000映射至另一份自有骨数组，
0xb0000映射至自有mesh字节；不是进程地址。下一帧恢复来自重新创建正常fixture，
不是证明外部数据或现场游戏恢复。
