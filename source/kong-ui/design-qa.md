## 五项检查

- 字体：Segoe UI / Microsoft YaHei UI；菜单主设置与数值最终为 16px，标题、导航及辅助字层级清楚，没有文字截断。
- 布局：窄侧栏、紧凑顶栏、同面分组行；默认视觉设置占完整内容宽度，预览展开后滑条缩短以容纳双列。启动窗页脚固定，展开详情时 QQ 仍完整可见。
- 颜色：默认静态蓝灰，未出现旧红色扫描与发光条。原主题选择可改变界面，自定义卡片色 `#233142` 实测生效。
- 图像：Kong 四格标识使用官方图标；人物预览使用原程序图片资源，已确认正常加载，无破图。
- 文案：双界面名称与 QQ 正确；状态来自已有 UI/宿主信息；更新内容入口与授权时间线已隐藏，准备阶段没有卡密加载提示；保存反馈进入页内状态条。

## 修复与复核记录

1. 初轮发现预览占用半页、字体偏密、旧装饰特效残留。改为按需展开预览、默认无特效，并将设置行及数值提高到 16px / 46px 行高。最终证据为 `menu-browser.jpg` 和 `menu-preview.jpg`。
2. 静态二读发现强制主题变量会压住自定义配色。取消该覆盖并引用原主题变量，实测主题切换与自定义颜色有效。
3. 启动窗展开详情后页脚被挤出视口。将页脚移到主滚动区外；500×300 复核中页脚 bottom=299，QQ 完整可见，证据为 `launcher-expanded.jpg`。
4. 最终原图与实现同屏复核，并补充局部字体对照。没有剩余的 P0/P1/P2 UI 问题；上述密度和流程差异属于保留原产品功能的明确约束，不声称像素级复制。

早期问题保留在本会话截图中，目录内保留最终复核图。
